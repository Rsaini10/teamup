TeamUp Project Journal
Work Done
We worked on the initial frontend development of our project. TeamUp is a platform designed to
help students find teammates for projects and hackathons. We first planned the basic structure of the website and decided what information should be
displayed on the main dashboard. We then created the basic HTML structure and used CSS to design
the webpage. The following features were added to the frontend:TeamUp logo and navigation sidebar Dashboard section
Search bar for finding projects Recommended projects section
Project cards containing project names, skills and number of members My Projects section
Progress indicators for projects  User profile and skills section
Responsive layout for different screen sizes
At this stage, the project is a static frontend, so the project information is currently added manually
using HTML. Problems Faced
1. We were initially unsure about how to organize the HTML and CSS files. 2. We had difficulty deciding the layout and sections that should be included in the dashboard. 3. Some elements were not properly aligned while designing the webpage. 4. Making the webpage responsive for smaller screen sizes was challenging. How We Solved the Problems
1. We created a simple folder structure with separate HTML and CSS files. 2. We planned the dashboard according to the main features of TeamUp. 3. We used CSS Flexbox and Grid to properly arrange and align the elements. 4. We used CSS media queries to make the website responsive on different screen sizes. 5. We tested the webpage in the browser and made changes to the spacing, sizing and
alignment wherever required. Current Status
The basic static frontend of the TeamUp website has been completed using HTML and CSS. The
dashboard and its main sections have been designed successfully. Next Step
Our next step is to convert the frontend into React components and then start developing the
backend using Node.js and Express. After that, we will connect the application with MongoDB to
store user and project data.
